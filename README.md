# bss-project-portfolio
5인 팀으로 진행한 BSS 업무지원시스템 프로젝트의 담당 기능과 문제 해결 과정을 정리한 포트폴리오입니다.

## Git Collaboration

BSS에서는 GitHub Issue를 기준으로 작업 단위를 관리했습니다.

Issue
→ 기능별 Branch 생성
→ 기능 개발
→ Pull Request
→ 팀원 간 Code Review
→ 수정사항 반영
→ devel Merge
→ 통합 기능 확인
→ 최종 발표 전 main Merge

이전 LMS 프로젝트에서는 팀원별 브랜치에서 작업한 뒤
주 단위로 main에 병합하는 방식으로 협업했습니다.

BSS에서는 이를 발전시켜 Issue, Pull Request, Code Review,
devel 브랜치를 활용한 협업 방식을 적용했습니다.

> 본 프로젝트는 5인 팀 프로젝트이며,
> 저장소에는 제가 담당한 기능과 프로젝트에서 직접 수행한 내용을 중심으로 정리했습니다.
> 원본 소스 저장소는 Private으로 관리하고 있습니다.
