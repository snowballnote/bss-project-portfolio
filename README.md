# BSS 업무지원시스템

5인 팀으로 진행한 BSS 업무지원시스템 프로젝트입니다.

전자결재, 물품예약, 근태, 프로젝트 관리, 메신저, 캘린더 등의 기능을 제공하는 그룹웨어 형태의 웹서비스입니다.

## My Role

저는 **전자결재 백엔드와 물품예약 연동**을 담당했습니다.

- 전자결재 기안·상신·승인·반려·회수 기능 구현
- 현재 결재 순서와 사용자 역할에 따른 권한 검증
- 전자결재 결과와 물품예약 상태 연동
- 결재·예약 상태 불일치 확인 및 재정합 기능 구현
- 첨부파일 접근 권한 및 처리 기능 구현
- 요구사항 정의서·테이블 정의서 작성
- 프로젝트 종료 단계의 팀원별 일정 및 남은 작업 정리
- 팀 산출물 취합·누락사항·용어·형식 최종 검토
- 최종 발표자료 제작 및 발표 준비

## Git Collaboration

BSS에서는 GitHub Issue를 기준으로 작업 단위를 관리했습니다.

Issue  
→ 기능별 Branch 생성  
→ 기능 개발  
→ Pull Request  
→ 팀원 간 Code Review  
→ 수정사항 반영  
→ devel Merge  
→ 통합 기능 확인  
→ 최종 발표 전 main Merge

이전 LMS 프로젝트에서는 팀원별 브랜치를 생성하고 각자의 기능을 개발한 뒤 주 단위로 main 브랜치에 병합하는 방식으로 협업했습니다.

BSS에서는 이를 발전시켜 **Issue → Branch → Pull Request → Code Review → devel Merge** 방식으로 협업했습니다.
